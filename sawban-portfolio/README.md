# Mohammad Sawban Chowdhury — Personal Portfolio

A responsive, single-page professional portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files

* `index.html` — portfolio content and sections
* `style.css` — responsive layout, typography and colour system
* `script.js` — mobile navigation, theme toggle and current year
* `assets/profile-placeholder.png` — temporary portrait placeholder

## Preview locally

Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages

1. Create a repository named **`sawbanchowdhury.github.io`** under the GitHub account `sawbanchowdhury`.

   * If that repository name is already in use, create a normal repository such as `portfolio` and select the `main` branch / root folder in Pages settings.
2. Upload all files and folders in this project to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. The user site URL will be `https://sawbanchowdhury.github.io/`.

## Replace the portrait

The LinkedIn page is not a direct image URL, so the included PNG is a temporary placeholder. Save your chosen LinkedIn profile photo as `assets/profile.jpg`, then in `index.html` change:
`assets/profile-placeholder.svg` to `assets/profile.jpg`.
Use a photo you own or have permission to publish. A square or vertical, high-resolution portrait works best.
